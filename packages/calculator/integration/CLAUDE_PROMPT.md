Это облегчённый архив с полноценными исходниками. Готовой папки dist/ и тяжёлых моделей OCR в ZIP нет. Сначала выполни npm ci: postinstall восстановит public/ocr/ из npm-зависимостей. Затем npm test и npm run build. После этого используй полученный dist/ для интеграции. Не скачивай минифицированную версию с сайта вместо исходников.

Добавь «Калькулятор» как новое приложение VOIDEX, используя приложенные исходники. Сохрани дизайн: белые панели, лавандовые клавиши, фиолетовая кнопка результата, мягкие скругления. Виджет не нужен.

Сначала прочитай AGENTS.md и найди существующие регистрации приложений, компонент окна, оболочку мобильной версии и правила открытия/закрытия приложений. Используй тот же механизм, что для Почты и Настроек; не придумывай новую оконную систему.

Самый быстрый путь, сохраняющий проверенное поведение: скопировать содержимое dist/ в apps/web/public/apps/calculator/, добавить компонент integration/VoidexCalculator.tsx, зарегистрировать его как приложение. Внешнюю рамку, заголовок, перемещение/размер/закрытие окна контролирует оболочка VOIDEX. Калькулятор встраивается через ?embed=1 без собственного рабочего стола. Убедись, что iframe получает доступную высоту, а прокрутка позволяет видеть все кнопки на маленьком экране. Логотип для ярлыка: public/calculator-logo.jpeg.

Можно позже перенести интерфейс в обычные React-компоненты: движок src/engine.js независим от DOM, API solve(expression, angle), toTex(expression). Не импортируй src/main.js в React напрямую: он монтируется на document и рассчитан на самостоятельную страницу. Стилям src/style.css при переносе дай область действия контейнера приложения. При переносе OCR вычисляй workerPath/corePath/langPath относительно каталога assets приложения.

Сохрани обычный и научный режимы, точные дроби, сокращение некоторых квадратных корней, степени, логарифмы, тригонометрию RAD/DEG, линейные/квадратные/рациональные уравнения, полиномы до шестой степени, изолированный переменный квадратный корень, пошаговый разбор, проверку корней подстановкой, историю текущей сессии и копирование решения. Не представляй калькулятор как решатель абсолютно любых уравнений.

Сохрани два способа фото: камера через input capture="environment" и галерея, выделение участка, локальный Tesseract OCR, редактирование результата перед решением. OCR — обычный текстовый, не специализированное распознавание двумерной математики. Рукопись, дроби друг над другом и степени могут потребовать исправления. Не скрывай это и не подставляй демонстрационное уравнение вместо результата распознавания.

Не добавляй ИИ-API, серверные ключи, отправку фото или платные сервисы без отдельной задачи. Весь текущий калькулятор работает локально в браузере; модели OCR лежат в public/ocr/.

Проверь: 1250×4=5000; 1/3+1/6=1/2; sqrt(72)+sqrt(8)=8sqrt(2); x²−5x+6=0 → 2,3; sqrt(x+5)=x−1 → 4 с исключением −1; (x²−1)/(x−1)=2 → нет решений; фото печатного 2x+4=10 → распознавание и x=3; ошибка деления на ноль; мобильные размеры 390 и 320 px, десктоп 1440 px, уменьшенное окно приложения. Используй существующие CI проверки репозитория, сначала покажи результат и затем следуй действующим правилам merge/deploy.
