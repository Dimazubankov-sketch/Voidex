# Voidex Calculator — облегчённые исходники

Рабочее самостоятельное веб-приложение и пакет для встраивания в VOIDEX. Виджета нет.

В этом ZIP нет готовой сборки и тяжёлых моделей OCR. Они автоматически восстанавливаются из зафиксированных npm-зависимостей при `npm ci`. Дизайн, исходники, тесты, логотип и адаптер сохранены.

## Запуск

Node.js 20+, `npm ci`, `npx vite --host 0.0.0.0`. Сборка: `npm run build`. Проверки математического движка: `node tests/engine.test.mjs`. После `npm run build` собранные файлы появятся в `dist/`; открывайте их через HTTP(S), не через file://.

## Возможности

- Обычный калькулятор с клавиатурой, процентами и историей текущей сессии.
- Научный режим: точные дроби, некоторые точные квадратные корни, степени, sqrt/cbrt/nthRoot, log/ln, модуль, факториал, тригонометрия, RAD/DEG.
- Линейные, квадратные и рациональные уравнения с x. Полиномы до 6-й степени: действительные корни численно. Изолированный переменный корень вида sqrt(x+5)=x−1, с проверкой посторонних корней.
- Пошаговое решение и математическая запись через KaTeX.
- Камера, галерея, выделение области изображения, локальное OCR и исправление распознанного выражения.
- Адаптация: на ПК две колонки; до 700 px калькулятор над разбором. Встраиваемый режим `?embed=1` убирает оболочку рабочего стола.

## Передача в Claude

Отдайте этот архив вместе с репозиторием VOIDEX. Готовая инструкция — `integration/CLAUDE_PROMPT.md`. React-адаптер — `integration/VoidexCalculator.tsx`. Сначала выполните `npm ci` и `npm run build`. Для быстрого подключения скопируйте содержимое созданного `dist/` в `apps/web/public/apps/calculator/` и зарегистрируйте адаптер в существующем реестре приложений. Пути ассетов и OCR рассчитаны на подпапку приложения. Сам репозиторий VOIDEX в рамках этой сборки не изменялся.

Для переноса в React используйте независимый `src/engine.js`. `src/main.js` — самостоятельный DOM-интерфейс, не React-компонент. CSS требуется ограничить контейнером при прямом переносе. Через iframe CSS изолирован автоматически.

## Границы первой версии

Это детерминированный математический движок, без ИИ и без серверного API. Не решает системы, несколько переменных, общие трансцендентные уравнения, интегралы или произвольные комбинации переменных корней. Вычисления в действительных числах; комплексные корни не выдаются. Численные корни и иррациональные значения помечены как приближённые. Ограничения указаны в помощи приложения.

OCR — Tesseract с английской моделью для цифр и латинских математических символов. Он работает с печатными линейными формулами; рукопись, степени и двухмерные дроби могут распознаться неверно. Проверьте текст перед решением; для многострочного распознавания оставьте одно уравнение. Камера доступна на HTTPS и зависит от поддержки capture браузером; на ПК обычно открывается выбор файла. Фото и история не отправляются на сервер. OCR-модель загружается только при первом распознавании.

## Проверено

27 проверок правильных результатов и отказов: дроби, корни, углы, линейные/квадратные/рациональные уравнения, посторонние корни, полином, деление на ноль, недопустимые функции. OCR реального тестового PNG «2x + 4 = 10» распознал выражение и получил x=3. Производственная сборка проходит. Проверка адаптивных стилей выполнена по исходникам; визуальная проверка в браузере этой среды не выполнялась. Необязательный WebMCP регистрируется при поддержке browser API; проверка в совместимом WebMCP браузере недоступна.

## Структура

`src/engine.js` — разбор и вычисления; `src/main.js` — UI, ввод, фото/OCR; `src/style.css` — интерфейс; `public/calculator-logo.jpeg` — предоставленный логотип; `public/ocr/` — локальные модули/модель распознавания; `tests/engine.test.mjs` — проверки; `dist/` — сборка, создаётся командой `npm run build`.
