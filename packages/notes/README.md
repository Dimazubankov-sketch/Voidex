# @voidex/notes

Voidex Notes document logic (Step 2.6): pages of a note, Note → Presentation,
reflowing slides between square and widescreen, overflow checks. Pure
TypeScript over the shapes in `@voidex/shared` (`notes.ts`); the Notes app UI
lives in `apps/web/src/apps/notes`. Tests: `pnpm --filter @voidex/notes test`.
